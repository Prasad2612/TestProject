⚠️ QUICK TROUBLESHOOTING

Problem: Maven not found
└─ Fix: Download from https://maven.apache.org/download.cgi
   Then add to Windows PATH

Problem: File not found
└─ Fix: Verify PBP_CV.docx exists in PRODATA folder
   Check filename spelling and .docx extension

Problem: Build failed
└─ Fix: Run: rmdir /s /q target
   Then: mvn clean compile

Problem: Permission denied
└─ Fix: Run Command Prompt as Administrator
   Or check folder write permissions
