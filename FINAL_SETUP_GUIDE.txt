───────────────────────────────────────────────────────────────────────────────
                      ⚠️ COMMON ISSUES & FIXES
───────────────────────────────────────────────────────────────────────────────

ISSUE 1: "Maven command not found"
FIX:
  1. Download Maven: https://maven.apache.org/download.cgi
  2. Extract to: C:\Maven
  3. Add to Windows PATH:
     - Right-click "This PC" → Properties
     - Advanced system settings → Environment Variables
     - Add: MAVEN_HOME = C:\Maven
     - Edit PATH and add: %MAVEN_HOME%\bin
  4. Restart Command Prompt
  5. Verify: mvn -version


ISSUE 2: "Java not found"
FIX:
  1. Download Java 21: https://www.oracle.com/java/technologies/javase/jdk21-archive-downloads.html
  2. Install to default location
  3. Restart Command Prompt
  4. Verify: java -version


ISSUE 3: "File not found: PBP_CV.docx"
FIX:
  1. Check file exists at: C:\Users\pmspp\AppData\Roaming\JetBrains\...
  2. Verify filename is exactly: PBP_CV.docx
  3. Check file extension is .docx (not .doc)
  4. If missing, copy/paste file to that location


ISSUE 4: "Build failed"
FIX:
  1. Delete target folder: rmdir /s /q target
  2. Rebuild: mvn clean compile
  3. Check internet (Maven downloads dependencies)


ISSUE 5: "Permission denied"
FIX:
  1. Run Command Prompt as Administrator
  2. Check PRODATA folder write permissions
  3. Close Word document if open
  4. Close any file explorers
